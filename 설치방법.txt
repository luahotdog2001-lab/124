ENGLISH BATTLE - 로그인/관리자 통합본

[파일 배치]
index.html
styles.css
game.js
auth.js
supabase-schema.sql
assets.js (기존에 사용하던 파일이 있다면 함께 배치)
assets/ (기존 이미지·사운드 폴더가 있다면 함께 배치)

1. Supabase 프로젝트를 생성합니다.
2. Supabase Dashboard > SQL Editor에서 supabase-schema.sql 전체를 실행합니다.
3. Project Settings > API에서 Project URL과 anon/publishable key를 복사합니다.
4. auth.js 맨 위의 아래 두 값을 교체합니다.
   SUPABASE_URL = 'YOUR_SUPABASE_PROJECT_URL'
   SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY'
   service_role 키는 절대 넣지 마세요.
5. Supabase Authentication 설정에서 이메일 가입을 켭니다.
6. 첫 관리자 계정을 사이트에서 회원가입합니다. 이메일 인증 설정이 켜져 있다면 인증까지 완료합니다.
7. SQL Editor에서 아래 쿼리를 실행하되 이메일을 실제 관리자 이메일로 바꿉니다.
   update public.profiles set role='admin' where email='관리자이메일';
8. 이 폴더 안 파일을 GitHub Pages 배포 폴더에 모두 올립니다. 파일 경로/이름을 바꾸지 마세요.

[현재 연결된 관리자 기능]
- 회원 검색/목록/상세 식별
- 회원 계정 정지 및 복구
- 관리자 권한 부여 및 회수 (자기 권한 변경 차단)
- 공지 등록 및 조회
- 관리자 작업 감사 로그
- 회원/정지/관리자 기본 통계
- 100개 운영 기능 카탈로그

나머지 게임 서버 제어·재화·아이템·실시간 채팅 제재 기능은 현재 원본 PeerJS 게임 구조에 맞는 서버 권한 RPC가 추가로 필요하며, 관리자 패널에서 '서버 기능 연결 필요'로 구분 표시합니다. 브라우저 화면만으로 실제 게임 서버 권한을 안전하게 조작하는 가짜 버튼은 만들지 않았습니다.
